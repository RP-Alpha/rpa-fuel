# rpa-fuel

A hybrid fuel system for FiveM vehicles.

## Features
- **Target & Legacy Support**: Refuel via Eye target or by staying near pumps.
- **Consumption Logic**: RPM and vehicle class based fuel usage.
- **Nozzle Props**: Renders fuel nozzle props when refueling.

## Installation
1. Ensure `rpa-lib` is started.
2. Add `ensure rpa-fuel` to your `server.cfg`.

## Usage
- Go to a gas station.
- Use Third Eye on the pump/nozzle to refuel.
